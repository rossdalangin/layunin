LAYUNIN GUTENBERG BLOCK MASTERCLASS
ARCHITECTING PREMIUM CONTENT WITH CORE BLOCKS

The Layunin v9.8 theme is optimized to transform standard Gutenberg blocks into premium, high-contrast components. Follow these protocols for aesthetic consistency.

1. THE "ELITE" HEADING STRUCTURE
- Protocol: Always start with an H2. If the section is dense, use H3s for modular sub-topics.
- Aesthetic Tip: In the block settings, under "Typography," set the line height to 1.1 or 1.2 for that "Playfair Display" architectural look.

2. COLUMNS & GRID HARMONY
- Protocol: Use the 2-Column or 3-Column block for benefit lists or features.
- Tip: Set the "Vertical Alignment" to "Center" for professional symmetry.

3. THE "GOLDEN" SPACER BLOCK
- Protocol: Use the Spacer block (set to 50px or 80px) between major sections within a post to maintain the Golden Ratio rhythm.
- Do not crowd your content. White space (or Navy space) is a sign of elite design.

4. CALL-TO-ACTION (CTA) BUTTONS
- Protocol: Use the standard Button block.
- Style: Select "Fill." Under "Colors," use your Elite Gold as the background and Navy as the text.
- Border Radius: The theme automatically applies your global 16px radius to all buttons.

5. PREMIUM IMAGERY & MEDIA
- Protocol: Always use high-resolution, wide-aspect images (1200x800px).
- Block Setting: Add the "shadow-sm" or "shadow-premium" class to the image block (under Advanced > Additional CSS Classes) for a floating depth effect.

6. QUOTES & PULL-QUOTES
- Protocol: Use the Pull-quote block. The theme injects a watermark icon and Playfair Display italics for maximum impact.
